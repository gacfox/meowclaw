# 工具

MeowClaw 的智能体可以使用系统内置工具，也可以通过 MCP 接入外部工具。内置工具默认全部启用，以提供完整的智能体能力；在智能体配置界面可以关闭其中任意工具，也可以关闭全部工具，将智能体作为纯聊天机器人使用。

## 内置工具

| 工具 | 作用 |
| --- | --- |
| `cd` | 切换会话级的基础工作路径，默认值为智能体的工作区路径。 |
| `read` | 读取文件；在主模型具备 `vision` 能力时，也可以图片形式读取受支持的图片文件。 |
| `edit` | 编辑（更新）文件。 |
| `grep` | 在文件中使用正则表达式搜索。 |
| `glob` | 查找文件。 |
| `skill` | 加载 Agent Skill。 |
| `write` | 追加或覆盖写文件。 |
| `powershell` | 在 Windows PowerShell 中执行命令。 |
| `bash` | 在 Linux/macOS Bash 中执行命令。 |
| `memory_write` | 异步写入长期记忆，提交后立即返回，不阻塞对话。 |
| `memory_recall` | 召回长期记忆。 |
| `spawn_subagent` | 创建子智能体。 |

其中，`cd` 改变的是当前会话的基础工作路径。智能体默认在自己的工作区中工作，避免将工作产生的文件随意写入操作系统的其他位置。

## 使用 `read` 读取图片

`read` 可以直接读取图片并让模型“看到”图片内容，但须同时满足以下条件：

- 文件格式为 png、jpeg、webp 或 gif；
- 单张图片不超过 10 MB；
- 智能体的主模型具备 `vision` 能力。

不满足这些条件时，不能通过 `read` 以图片形式读取文件。聊天消息直接上传图片同样要求主模型具备 `vision` 能力：配置该能力后，输入框旁的图片上传按钮可用，否则按钮置灰。每条消息最多携带 5 张图片，格式和单张大小限制与 `read` 相同，图片以 Base64 内联方式发送给多模态模型。

当前及最近 4 个历史 batch 中的图片会在后续对话中继续携带，更早的图片会省略为文本占位；`read` 工具读取的图片遵循相同的保留规则。单次请求的图片 Base64 总量上限为 8 MB，超出时优先省略较旧图片并保留文字说明，以控制请求体积。

## MCP 外部工具

MCP 工具用于按需扩展智能体的外部能力。用户可以在「MCP 工具」菜单中添加外部 MCP 工具，再在智能体配置中启用它们，例如接入 context7、Tavily、Firecrawl 等服务。

MeowClaw 支持以下三种 MCP 交互协议：

- **stdio**；
- **Streamable HTTP**；
- **SSE（Legacy）**。

内置工具和 MCP 工具的实际执行均受当前会话的安全护栏策略约束。
