# 配置导入与导出

系统配置页面支持导入、导出智能体相关配置，用于备份或迁移 MeowClaw 实例中的配置。

## 导入与导出范围

配置范围包括：

- 智能体；
- MCP 服务；
- 定时任务；
- 大语言模型；
- 向量嵌入模型；
- 护栏策略；
- 环境变量。

## 明文密钥警告

**导出文件包含明文密钥等敏感信息。** 请像保管密码一样妥善保管导出文件，避免通过不受信任的渠道传输、公开分享或长期放置在无访问控制的位置。

## 导入行为

- **不覆盖现有配置**：导入不会覆盖目标实例中已有的配置。
- **尽力恢复跨实例关联**：系统会尽力恢复智能体与模型、MCP 服务、定时任务等相关配置之间的关联，包括专业子智能体授权关系；关联目标未能导入时，会跳过对应关系并给出提示。
- **MCP 服务导入后保持禁用**：需要在导入后检查配置，并手动启用所需服务。
- **定时任务导入后保持禁用**：需要在确认任务配置和执行环境无误后，再手动启用，避免迁移后立即自动执行。
