# MeowClaw 简介

MeowClaw（喵爪智能体）是一款**可自托管的单用户 ReAct 风格通用智能体工具**。首次使用时需要创建管理员账户；系统采用单用户模式，管理员拥有全部操作权限，后续可以在后台修改用户名和密码。

## 核心能力概览

### ReAct 智能体与多轮对话

- 可创建多个智能体，并分别配置名称、头像、人设、模型、工具、子智能体和工作区。
- 人设会固定注入系统提示词；主 LLM 负责智能体执行，辅助 LLM 负责生成标题、压缩上下文等任务。
- 一个对话批次（batch）包含一次完整的智能体交互，可经历多次模型调用与工具调用迭代；模型不再发起工具调用后，最后一段正文作为最终答复。
- 较早的批次会根据模型上下文大小进行多级压缩，以支持长流程对话。上下文圆环会展示最近一次 LLM 请求的 prompt tokens 占模型上下文长度的比例。
- 智能体执行与页面连接解耦：刷新浏览器或切换会话不会中断任务，重新进入会话时可恢复流式输出现场，不同会话也可并行执行。

### 工具、工作区与能力扩展

- 内置文件读写、搜索、命令执行、长期记忆、子智能体等工具，可按智能体启用或关闭。
- 每个智能体可配置默认工作区，会话拥有独立的当前工作目录（CWD）；工作区管理菜单提供在线文件浏览与维护能力。
- 支持通过 MCP 接入外部工具，兼容 stdio、Streamable HTTP 和 SSE（Legacy）三种交互协议。
- 支持上传、展示和部署 Agent Skill。部署后，Skill 位于智能体工作区的 `.skill/` 目录，可通过 `skill` 内置工具使用。
- 主模型配置 `vision` 能力后，可在对话中上传图片，也可以通过 `read` 工具让模型读取图片。

### 长期记忆、子智能体与定时任务

- 长期记忆按智能体跨会话生效，结合 BM25 与向量检索召回记忆及相关实体；也可开启“激进记忆召回”，在每次用户输入时自动召回并注入相关记忆。
- 父智能体可以通过 `spawn_subagent` 异步派发一次性子任务，多个子任务可并发运行，结果自动汇总回父智能体。
- 定时任务使用 Quartz 风格的 Cron 表达式，将自然语言命令定时发送给智能体，可固定在同一个会话执行，也可每次创建新会话。

### 安全、模型与运维能力

- [模型集成](models.md)：支持 OpenAI 兼容的聊天与向量嵌入接口，并可配置思考强度。
- [安全护栏](guardrails.md)：在工具执行前按策略放行、拒绝或请求审批，支持三种内置模式与自定义 JSON 策略。
- [观测与统计](observability.md)：提供 tokens 日聚合、批次缓存 tokens 与输出速度、LLM 追踪以及系统资源监控。
- [配置导入与导出](config-transfer.md)：迁移智能体及其相关配置，并尽力恢复跨实例关联。

## 技术栈

- **后端**：Java、Spring Boot、H2、Lucene。
- **前端**：React、Vite、Tailwind CSS、shadcn/ui。
- **智能体框架**：项目使用专门开发的轻量级 Agent 框架 `proarc-agentic`，不依赖 LangChain4J 或 Spring AI 等重型框架。

MeowClaw 的后端会将前端静态资源一并打入 JAR，前后端可共用同一个服务端口，无需单独部署前端。
