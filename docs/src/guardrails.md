# 安全护栏

MeowClaw 为智能体的工具调用提供可配置的安全护栏。每次工具真正执行前，系统都会按当前策略求值，并决定：

- **放行（allow）**：直接执行工具。
- **拒绝（deny）**：拒绝执行，并向模型返回固定的拒绝结果。
- **审批（ask）**：挂起工具调用，等待用户批准或拒绝。

## 三种内置模式

### 手动审批模式

所有工具调用均需用户审批。

### 工作区读写模式（默认）

- 工作区内的文件读写直接放行。
- 工作区外的文件读写需要审批。
- 全部 `powershell` / `bash` 命令执行需要审批。
- 全部 MCP 工具调用需要审批。
- 记忆工具直接放行。

### 无限制模式

所有工具调用自动执行，不询问用户。

> 无限制模式下，启用全部内置工具的智能体拥有很高的操作权限。操作不当可能导致文件损坏，甚至使电脑或云主机失联，请谨慎使用。

## 切换策略与会话继承

会话输入框的盾牌下拉菜单可随时切换当前会话生效的策略。选择会**按智能体**保存在浏览器 `localStorage` 中，同一智能体的新旧聊天会话都会自动继承。

**定时任务会话保持独立设置**。定时任务无人值守，其安全护栏默认生效“无限制模式”，不会继承普通聊天会话在浏览器中的选择。

## 审批面板与审批记录

需要审批时，输入框上方会出现审批面板，展示：

- 工具名称；
- 关键参数；
- 命中的规则。

可使用以下快捷键：

| 快捷键 | 操作 |
| --- | --- |
| `Y` / `Enter` | 批准 |
| `N` / `Esc` | 拒绝 |

也可以直接中断本轮执行。批准后，该工具继续执行；拒绝后，系统向模型返回固定的拒绝结果。审批记录会作为独立事件渲染在 AI 回复气泡中，并可展开查看。

## 自定义 JSON 策略

左侧“安全护栏策略”菜单支持使用纯 JSON 自定义策略。例如：

```json
{
  "defaultDecision": "deny",
  "rules": [
    {
      "tools": ["read", "write", "Tavily__tavily_search", "Tavily__*"],
      "paths": ["${cwd}/**", "**/config/*.json"],
      "action": "allow"
    }
  ]
}
```

### 匹配语义

- `rules` 按从上到下的顺序求值，**首个命中规则生效**；没有任何规则命中时使用 `defaultDecision`。
- `defaultDecision` 和规则的 `action` 可取 `allow`、`ask` 或 `deny`。
- `tools` 支持 `*` 通配。例如，`Tavily__*` 匹配 Tavily 这个 MCP 服务的全部工具。
- `paths` 是可选的 Ant 风格路径模式；`${cwd}` 占位符表示智能体当前工作目录。
- `paths` 仅对包含 `path` 参数的内置文件工具有效。没有路径参数的工具（如 `powershell`、`bash`）不受 `paths` 约束。
- 路径匹配统一忽略大小写，且不区分 `\` 与 `/` 分隔符。
- 相对路径会先按 `cwd` 解析为绝对路径，再进行匹配。
- 不以分隔符开头的模式（如 `**/config/*.json`）会同时匹配绝对路径与相对 `cwd` 的路径，各平台行为一致。
- 如果只需限定工作区，建议使用 `${cwd}/**` 形式。
