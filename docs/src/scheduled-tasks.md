# 定时任务

定时任务用于按照计划自动将自然语言命令发送给智能体，无需用户在任务触发时手动输入。

## Quartz Cron 调度

定时任务支持配置 **Quartz 风格的 Cron 表达式**，由该表达式决定自然语言命令的发送时间。

## 会话执行方式

每个定时任务可以选择以下两种会话方式之一：

- **固定会话**：任务固定在一个会话中执行；
- **每次新建会话**：每次执行任务时都重新创建会话。

## 无人值守与安全护栏

定时任务会话属于**无人值守**执行，安全护栏默认生效的是**无限制模式**，即工具调用自动执行，不询问用户。

因此，配置定时任务时，应同时确认目标智能体具备的工具权限和将执行的自然语言命令，避免无人值守的自动工具调用造成非预期操作。
