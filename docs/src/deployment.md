# 部署

## 单 jar 部署

按照[快速开始](getting-started.md)完成前端与后端构建后，后端会把前端静态资源一并打入 jar。进入构建产物目录并启动：

```bash
cd meowclaw/target
java -jar meowclaw-0.0.1-SNAPSHOT.jar
```

服务默认监听 `127.0.0.1:8080`，前后端共用 `http://127.0.0.1:8080`。部署时只需运行这个 jar，无需单独部署前端，也无需配置 Nginx 转发前端请求。

## history 路由回退

后端会将前端 history 路由自动回退到 `index.html`，因此可以直接访问或刷新 `/memory`、`/trace` 等页面。

以下路径不参与路由回退：

- `/api/**`
- `/upload/**`
- 静态文件路径

## 环境变量

| 环境变量 | 说明 |
| --- | --- |
| `MEOWCLAW_DATA_DIR` | MeowClaw 数据目录，用于保存系统数据库文件、智能体工作区等；默认为 `<当前路径>/data`。 |
| `MEOWCLAW_SPRINGDOC_ENABLED` | 是否开启接口文档，默认为 `false`。设为 `true` 后可访问 `/v3/api-docs` 和 `/swagger-ui/index.html`。 |

如需改变数据位置或开启接口文档，请在启动 jar 前设置相应环境变量。

## 安全提醒

1. **不建议将 MeowClaw 暴露到公网。** 部署在云主机上时，推荐使用 SSH 隧道转发到本地端口访问。
2. **谨慎使用“无限制模式”。** MeowClaw 智能体本质上等价于一个操作系统的 Shell。当安全护栏策略选择“无限制模式”，且智能体配置了全部内置工具时，其权限非常高；操作不当可能意外导致电脑或云主机失联、文件损坏等情况。
3. **妥善保管配置导出文件。** 智能体相关配置的导出文件包含明文密钥等敏感信息。
