# 对话与执行

## batch 与 ReAct 循环

MeowClaw 的一次完整智能体交互称为一个“轮”（batch）。一个 batch 包含：

- 1 条用户消息（User Message）；
- 若干助手正文；
- 带工具调用的助手消息（Assistant Message with Tool Call，可能还包含 reasoning 信息）；
- 工具消息（Tool Message，即工具调用的返回值）。

模型不再发起工具调用时，本次工作结束，最后一轮正文作为最终答复显示给用户。虽然一个 batch 会合并显示在一个对话气泡中，但其中可能包含数十次迭代，每次迭代都会调用大语言模型接口。

## 多轮对话与持续执行

多轮对话中，较早的 batch 会根据所配置大语言模型的上下文大小自动进行多级压缩，以便在尽量不丢失上下文记忆的前提下持续交互。

智能体执行与页面连接是解耦的：

- 刷新浏览器或切换会话不会中断正在执行的任务；
- 重新进入会话时，会从执行起点恢复流式输出现场；
- 左侧会话列表会标记正在执行的会话；
- 不同会话可以并行执行各自的智能体任务。

## 长流程纠偏与停止

每个 batch 的 ReAct 循环默认不限制轮数，以支持长流程复杂任务。每完成 50 轮，系统会在下一次 LLM 调用前自动注入一次纠偏提醒，要求模型：

- 复盘当前进展；
- 避免重复推理和相同工具调用；
- 如果已经完成，及时提交最终回答。

执行期间也可以随时点击停止按钮中断任务。

## 上下文占用圆环

对话输入框右侧的上下文占用圆环，显示最近一次 LLM 请求的 prompt tokens 占模型上下文长度的比例。

- 每次 LLM 响应完成后，圆环会实时刷新；
- batch 结束后会保存快照，供切换会话或刷新页面后恢复；
- 新会话没有上下文快照时，不展示圆环。

## 钉选、项目与分页

会话列表分为“已钉选”“项目”“会话”三个可折叠分组。

### 已钉选

点击会话的钉选按钮，可将其固定到顶部“已钉选”分组；再次点击，或通过菜单取消钉选后，会话会回到“会话”分组。

### 项目

项目类似会话的分类目录：

- 项目归属于智能体，同一智能体内的项目名唯一；
- 可通过会话行菜单中的“移入项目”归档会话；
- 可以在项目内直接新建会话；
- 项目中的会话也支持钉选，此时会同时显示在“已钉选”和项目内。

> **注意：** 删除项目会级联删除其中的全部会话。

### 会话与分页

“会话”分组收纳所有未钉选且未分组的会话，支持下滑自动分页加载。

## 图片输入

当智能体的主 LLM 配置了 `vision` 能力标签时，聊天输入框旁会出现可用的图片上传按钮；未配置该能力时，按钮置灰。

图片输入遵循以下规则：

- 每条消息最多携带 5 张图片；
- 支持 png、jpeg、webp、gif；
- 单张图片不超过 10MB；
- 图片以 Base64 内联方式发送给多模态模型。

### 历史图片保留与 8MB 预算

当前及最近 4 个历史 batch 中的图片，会在后续对话中继续携带；更早的图片会省略为文本占位。`read` 工具读取的图片也遵循相同的保留规则。

单次请求的图片 Base64 总量上限为 **8MB**。超出上限时，系统会优先省略较旧的图片，并保留文字说明，以控制请求体积。
