# 智能体工作区

## 工作区与 CWD

智能体工作区是智能体默认的工作目录，可在智能体配置的“工作区路径”中设置。

每次会话都有独立的 CWD（当前工作目录），其默认值就是智能体工作区。因此，智能体工作时产生的文件默认会优先写入自己的工作区，而不是在操作系统中随意写入。内置 `cd` 工具可以切换会话级的基础工作路径，其默认值同样是工作区路径。

多个智能体可以配置相同的工作目录，但如果它们同时运行，可能产生文件冲突，使用时需要注意。

## 文件浏览器

左侧的“工作区管理”菜单提供在线文件浏览器。页面顶部可切换智能体，并通过面包屑或“上一级”导航目录。

“查看”按钮支持三种显示方式：

- **大图标**：便于浏览图片和区分文件类型；
- **中图标**：在有限空间内显示更多条目；
- **详细**：以表格展示名称、大小、类型和修改时间。

查看方式会保存在浏览器中。文件和文件夹使用不同的图标，图片、音视频、压缩包、代码、终端脚本和表格等常见文件类型也有各自的图标。

### 选择与打开

- 单击条目：选中该条目；
- `Ctrl` / `Cmd + 单击`：切换条目的选中状态，进行多选；
- `Shift + 单击`：连续选择两个位置之间的条目；
- 双击文件夹：进入文件夹；
- 双击文件：打开预览，支持的文本文件还可在线编辑；
- 单击空白区域：取消选择。

文件区域还支持 `Ctrl+A` 全选、`Ctrl+C` 复制、`Ctrl+X` 剪切、`Ctrl+V` 粘贴、`F2` 重命名和 `Delete` 删除。输入框与弹窗内不应用这些文件快捷键。

### 触屏交互

手机和平板等触屏设备使用独立的浏览与选择模式，不需要双击或右键：

- 浏览模式下单击文件夹直接进入，单击文件直接预览；
- 长按条目会打开底部操作菜单，可执行打开、下载、复制、剪切、粘贴、重命名、删除或查看属性；
- 点击操作菜单中的“多选”，或工具栏中的“选择”，进入选择模式；
- 选择模式下会显示复选框，单击条目只切换选中状态，可全选并执行批量操作，点击“完成”退出；
- “更多”提供当前目录的新建、上传、粘贴和刷新操作，长按不是访问这些功能的唯一方式。

触屏模式根据设备的主要指针和悬停能力判断，而不是仅根据屏幕宽度判断。长按期间移动手指滚动列表会取消操作菜单。

### 工具栏与右键菜单

工具栏提供新建文件、新建文件夹、上传、复制、剪切、粘贴、重命名、下载、删除和属性操作。条目上的右键菜单提供相同的主要操作；目录空白处的右键菜单可用于粘贴、新建、上传和刷新。

复制与剪切仅限在**同一个智能体工作区**内粘贴。复制文件夹会递归复制其内容；剪切粘贴会移动条目。禁止将文件夹复制或移动到自身及其子目录中。

目标位置出现同名条目时，可以选择：

- **覆盖**：以来源内容替换目标；
- **跳过**：不处理该条目；
- **保留两者**：自动添加序号，以来源和新名称同时保留。

批量操作时可选择将同一策略应用到后续冲突。删除文件或文件夹不可撤销，执行前需要确认。

### 下载与属性

- 单个文件直接下载；
- 文件夹自动打包为 ZIP；
- 多个文件或文件夹打包为一个 ZIP，并保留文件夹内部结构。

属性弹窗显示文件数、文件夹数、总大小和修改时间。文件夹及多选内容会在打开属性时递归统计。

## 分块上传

上传支持一次选择多个文件。文件按约 5 MiB 分块顺序上传，底部上传面板显示每个任务的目标目录、已上传量、总大小、百分比和状态。

上传任务支持：

- **暂停**：中止当前分块并停止调度后续分块；
- **继续**：查询服务端已确认的分块后续传；
- **取消**：中止任务并清理服务端临时分块；
- **失败重试**：网络异常导致失败后手动继续。

上传进度以服务端已确认接收的数据为准。所有分块完成后，服务端先在工作区外合并并校验文件，再放入目标目录。同名文件同样支持覆盖、跳过和保留两者。

### 离开页面与刷新

通过 MeowClaw 侧边栏或站内路由切换到聊天、记忆等其他页面时，上传队列仍在后台继续，上传面板会折叠为全局悬浮入口，可以继续管理任务。

**刷新页面、关闭标签页或退出浏览器可能中断上传。** 有活动任务时浏览器会显示离开提醒。浏览器无法在这些场景后自动恢复原始文件句柄，因此不承诺刷新后自动续传。
