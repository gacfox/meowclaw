# 智能体配置

在左侧“智能体管理”菜单中可以创建智能体。智能体是 MeowClaw 运行 ReAct 风格任务的核心对象。

## 配置项

| 配置项 | 说明 |
| --- | --- |
| 智能体名称 | 智能体的名字。 |
| 头像 | 可上传一张图片，显示在智能体对话气泡旁边。 |
| 人设 | 描述智能体应以哪种身份、如何与用户交互。这部分文本会固定注入系统提示词，并在每一次与大语言模型交互时携带。 |
| 启用内置工具 | 配置智能体可使用的系统内置工具。内置工具默认全部启用，也可关闭部分工具，或关闭全部工具后将智能体作为纯聊天机器人使用。 |
| 启用 MCP 工具 | 配置智能体可使用的外部 MCP 工具；外部工具可先在“MCP 工具”菜单添加。 |
| Agent 执行 LLM | 智能体执行任务时使用的主大语言模型配置。 |
| 辅助 LLM | 用于生成标题、压缩上下文，通常配置为低成本、速度快的小参数规模模型。 |
| 向量嵌入模型 | 用于辅助长期记忆的语义存储和召回。 |
| 允许作为子智能体 | 开放后，其他智能体可将该智能体添加为专业子智能体。 |
| 专业子智能体 | 配置当前智能体可委派的专业子智能体列表。 |
| 工作区路径 | 智能体默认的工作目录。 |

此外，如果希望智能体始终携带记忆工作，而不依赖它主动调用 `memory_recall`，可以开启**激进记忆召回**。开启后，每次用户输入都会直接用于召回相关记忆，召回结果会自动注入系统提示词。

## 子智能体配置概览

“允许作为子智能体”和“专业子智能体”分别控制两个方向：

- **允许作为子智能体**：决定当前智能体是否能被其他智能体选用为专业子智能体。
- **专业子智能体**：决定当前智能体可以委派哪些已授权的专业子智能体。

具体的子任务创建、执行与结果汇总方式由子智能体专题文档说明。
