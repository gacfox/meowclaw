# 长期记忆

MeowClaw 支持**智能体级别、跨会话**的长期记忆。该能力依赖 `memory_write` 和 `memory_recall` 两个内置工具；为智能体配置这些工具，即意味着开启长期记忆功能。

## 异步写入与辅助 LLM 决策

`memory_write` 是异步写入工具。智能体调用后会立即返回，不阻塞当前对话，后续处理由 MeowClaw 在后台完成：

1. 自动召回与新内容最相似的已有记忆；
2. 调用**辅助 LLM** 决策如何处理新内容；
3. 根据决策跳过、删除、更新或插入记忆。

辅助 LLM 的决策语义如下：

- **重复内容**：跳过写入；
- **与已有记忆矛盾，或使已有记忆失效的内容**：删除对应旧记忆；
- **描述同一事实但更准确的内容**：更新已有记忆；
- **其余情况**：正常插入新记忆。

## 存储与图结构

插入的记忆会被抽取为**记忆和实体关系**，并使用 **Lucene 9** 存储倒排索引和向量；向量存储以配置了嵌入模型为前提。

记忆采用轻量级的**图结构**存储模型，记忆数据通过实体互相关联，而不是仅作为彼此孤立的文本条目保存。

## 混合召回

智能体调用 `memory_recall` 时，MeowClaw 会同时尝试召回：

- 相关记忆；
- 相关实体信息。

这些召回通常采用 **BM25 与向量检索的混合检索**。其中，向量能力依赖智能体配置向量嵌入模型。

## 记忆管理

左侧的「记忆」菜单提供记忆管理页面，可以按智能体查看和搜索记忆，也可以手动添加、编辑或删除记忆。

手动维护的记忆内容会**原样保存**，不经过模型提炼；这与 `memory_write` 写入时由后台召回相似记忆并调用辅助 LLM 决策的流程不同。

## 激进记忆召回

默认方式下，智能体通过主动调用 `memory_recall` 获取长期记忆。如果希望智能体始终携带记忆工作，而不依赖它主动调用该工具，可以在智能体配置中开启**激进记忆召回**模式。

开启后，每次用户输入都会直接用于召回相关记忆，召回结果会自动注入系统提示词。
