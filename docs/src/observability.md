# 观测与统计

MeowClaw 提供 tokens 消耗统计、批次级追踪观测和系统资源监控。这些能力用于了解模型成本、回溯智能体执行过程以及查看服务端资源占用。

## Tokens 消耗统计

统计图表界面可按**日聚合**统计已配置的所有模型，包括模型交互次数、tokens 消耗等信息，可在使用付费大语言模型接口时作为成本参考。

### 批次缓存 Tokens 与输出速度

对话页会在每个**已完成批次**的输入、输出 tokens 右侧显示以下信息：

- **缓存输入 tokens 汇总**：采用 Provider 上报的数据。缓存输入 tokens 已包含在输入 tokens 中，不是额外增加的消耗；仅当汇总值大于 0 时显示。
- **平均输出速度（tok/s）**：按批次内各次**主智能体 LLM 调用**的输出 tokens 总和，除以这些调用的总耗时计算。

缓存 tokens 与输出速度均随批次持久化，**不受追踪开关或追踪明细清理影响**。没有有效 usage 或耗时数据时，不显示输出速度。

## 追踪观测

MeowClaw 内置轻量级 LLM 交互追踪能力，类似简化版 LangSmith。每次智能体交互都会记录为一个可回溯的批次追踪。

左侧“追踪观测”菜单支持按以下条件检索：

- 智能体；
- 状态；
- 关键字；
- 时间范围。

### 批次追踪内容

点开任意批次，可以查看：

- **事件时间线**：该批次的思考、工具调用与返回、最终回答等完整事件流。
- **LLM 调用明细**：该批次内每一次 LLM 调用的完整信息，包括：
  - 调用用途：主循环、标题、摘要或记忆；
  - 请求消息列表；
  - 响应内容与推理内容；
  - 工具调用；
  - tokens 消耗、耗时与状态。
- **批次汇总**：状态、错误信息、tokens 消耗与耗时等。

### 删除、清空、开关与留存

- 追踪页面支持逐条删除、批量删除和清空追踪明细。
- 系统配置页面可开启或关闭新的追踪记录。
- 留存策略可设置为最近 1 天、最近 3 天、最近 7 天、最近一个月、最近一年或全部留存。
- 非“全部留存”策略会由后台任务异步清理过期数据。

**追踪与会话内容、tokens 统计相互独立**：关闭追踪或清理追踪明细，均不影响会话内容和 tokens 统计；已持久化的批次缓存 tokens 与输出速度也不受影响。

## 系统资源监控

系统配置页面可开启或关闭顶部系统资源监控。开启后：

- **桌面端**：以进度条展示服务端系统 CPU 和内存占用，每 **10 秒**刷新一次。
- **移动端**：通过顶部图标按钮打开弹出层查看；关闭弹出层后停止刷新。
