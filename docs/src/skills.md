# Agent Skill

Agent Skill 用于为智能体补充可复用的技能内容。MeowClaw 将 Skill 的全局管理与具体智能体中的部署分开：全局菜单负责上传、删除和展示，智能体只有完成部署后才能识别并使用相应 Skill。

## 上传与全局管理

在左侧的「SKILL」菜单中可以上传 ZIP 格式的 Agent Skill 压缩包。压缩包应包含：

- `SKILL.md`；
- 其他附属文件，包括可执行脚本等。

上传后，系统会自动读取 `SKILL.md` 中的 **YAML Frontmatter**，并以卡片形式展示 Agent Skill。

「SKILL」菜单只负责 Agent Skill 的上传、删除和展示。仅在这里上传并不会让智能体获得该 Skill；具体使用时，还需要将其部署到一个智能体中。

## 部署到智能体

已上传的 Agent Skill 可以部署到一个智能体。部署的实际操作是将压缩包解压到该智能体工作区下的 `.skill/` 目录：

```text
<智能体工作区>/.skill/
```

该目录下的内容都会被拥有此工作目录的智能体识别为自己拥有的 Agent Skill，并可通过 `skill` 内置工具访问。

## 一次性部署与删除

“部署”是一个**一次性操作**，UI 上没有直接的删除或撤回按钮。如果需要删除某个智能体的 Agent Skill，可以采用以下任一方式：

1. 在对应智能体工作目录的 `<智能体工作区>/.skill/` 下，删除以该 Agent Skill 名字命名的文件夹；
2. 直接与该智能体对话，让它删除工作空间内的指定 Agent Skill。

全局「SKILL」菜单中的管理与智能体工作区内的已部署副本应区分处理：要移除智能体实际使用的 Skill，需要删除其工作区 `.skill/` 下的对应目录。
